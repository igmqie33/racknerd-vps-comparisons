## 便宜 VPS 的几个常见坑，提前说清楚

**坑一：分到被墙的 IP。** 这个我自己碰过，买完发现国内 ping 不通。RackNerd 给了 72 小时免费换 IP 的窗口——购买后在 SolusVM 面板里有个 Change IP 按钮，点一下自助换，不要钱。超过 72 小时再换一次是 $3。所以买完第一时间先 ping 一下，不通立刻换。

**坑二：选错机房。** 有人图新鲜选了欧洲机房，结果国内访问延迟 300ms+，跑啥都慢。新手记住一句话：**人在国内就选美西，没第二条路**。预算够可以再买一台美东做冗余，但主力一定放西海岸。

**坑四：以为月付更灵活。** RackNerd 的便宜价格是建立在年付上的，月付方案价格会贵好几倍。如果你预算实在紧只能月付，那 RackNerd 不是最优解，可以考虑别家。但只要能年付，RackNerd 在这个价位段基本没有对手。
